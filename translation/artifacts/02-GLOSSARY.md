given in romaji only where a reading was the thing in question.

## Rank ladder (LOCKED -- ~60 strings inherit it)

Second Lieutenant -> First Lieutenant -> Captain -> Major -> Lieutenant
Colonel -> Colonel.

Abbreviations, used only where the byte budget forces them: **2Lt / Lt /
Capt / Maj / Lt Col / Col**. In dialogue, spoken address is the unabbreviated
title -- "Lieutenant", "Major" -- because that is what a person says.

**Trap:** Misa Hayase is a First Lieutenant for the first half and a Captain
after her return; the source marks the promotion and a line even comments on
it. Check the row's position before choosing her title.

## Forbidden renderings

| Rejected | Why |
|---|---|
| Rick Hunter, Lisa Hayes, Khyron, Breetai, Exedore, Dolza, Miriya, Max Sterling, Ben Dixon, Claudia Grant | Robotech. Different continuity, different audience. |
| "Robotech", "protoculture" as a fuel | Wrong franchise, wrong meaning. |
| "mecha", "mech", "robot" for a Valkyrie | The source uses its own words. One character says "a robot?" in astonishment at the *Macross* transforming; that is the only place the word belongs. |
| "Zentraedi", "Meltran" | Zentradi / Meltrandi. (The source does use a clipped "Meltran" in Zentradi mouths -- that one is kept, as their own shorthand.) |
| "Understood" / "Copy" for the acknowledgement | Splits a carrier that must be single. |
| "Captain" for Global *and* for the rank | Global is always "Captain Global" or "the Captain"; the rank is written out with a surname. |
| "SDF-1" alone in dialogue | Crew say "the Macross". |
| "attention all hands" for the scramble | It is a scramble, not an announcement. |
